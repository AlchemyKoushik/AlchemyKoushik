# Personalization checklist

The animated profile is wired up, but these values are intentionally left for you:

- GitHub username, exactly as it appears in your profile URL.
- Display name and terminal handle, if `Koushik Bhandary` / `koushik` are not what you want shown.
- One-line headline, for example `Data Analyst · Python Builder · Lifelong Learner`; update it in `README.md`.
- Portfolio, LinkedIn, email, and any other social links you want visible.
- A well-lit portrait photo. Put it at the repository root as `source-photo.jpg`, or change `source_photo` in `profile.json`.

After editing `profile.json`, run the commands in `README.md`. The workflow will then keep the contribution heatmap and statistics current.
